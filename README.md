# 📊 SAR — Stalzone Analytic Review (eAPI Edition)

**SAR (Stalzone Analytic Review)** — це аналітичний комплекс та веб-панель на базі Streamlit для моніторингу, збору та поглибленого аналізу статистики гравців у грі **Stalzone**. 

Версія інтегрована напряму з **офіційним eAPI Stalzone**, працює на базі баз даних **SQLite**, підтримує авто-планувальник зрізів та містить набір інструментів для кланлідерів і офіцерів (Конструктор загонів, Тирлисти, Персональні картки).

---

## ✨ Основні можливості та особливості

* **🔐 Вбудована система авторизації (Auth System):**
  * Захист аналітичної панелі логіном та паролем (`users.json`).
  * Підтримка розмежування доступу для адміністраторів та членів клану.

* **⚡ Пряма інтеграція з eAPI Stalzone:**
  * Повна відмова від веб-скрейпінгу (Camoufox/Selenium) на користь високої швидкості та надійності.
  * Пряме завантаження статистики за всіма режимами: **КВ (Кланові Війни)**, **Сесійні бої**, **Дуелі** та **Загальна статистика (Відкритий світ)**.

* **🗄️ База даних SQLite та авто-зрізи (Scheduler):**
  * Локальне збереження усієї історії гравців та зрізів у файлі `stalzone_stats.db`.
  * **Фоновий планивальник:** Автоматичний збір даних та фіксація зрізів статистики за розкладом (наприклад, до та після КВ) без участі користувача.

* **🎯 Управління блоками гравців (Block Management):**
  * Групування нікнеймів у списки/блоки (наприклад, "Основа", "Академія", "Загін #1").
  * Гнучке створення, редагування та видалення блоків.

* **📈 Поглиблений аналітичний рушій (Analytics Engine):**
  * Автоматичний розрахунок **дельти (приросту)** показників між зрізами: Вбивства (K), Смерті (D), K/D Ratio, Шкода, Виграні бої, Активність.
  * Фільтрація та порівняння прогресу за довільні проміжки часу.

---

## 🧩 Модулі та структура інтерфейсу

1. **🏆 Тирлист (Tier List):**
   * Автоматичний рейтинг гравців на основі обрахованої ефективності за обраний період чи КВ.
2. **👤 Персональна картка гравця:**
   * Детальний розбір статистики конкретного бійця, відсоток влучань, аналіз за режимами та графіки динаміки прогресу.
3. **⚔️ Конструктор загонів (Squad Builder):**
   * Спеціальний модуль для формування пачок/загонів на Кланові Війни.
   * Порівняння сумарних характеристик загонів та балансування складу під час підготовки до КВ.
4. **📊 Загальний аналіз клану:**
   * Зведена таблиця статистики всього списку з можливістю сортування, фільтрації та експорту результатів у **.csv** або **.xlsx**.
