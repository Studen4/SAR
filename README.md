# SAR - Stalzone Analytic Review

Інструмент для відслідковування та аналізу зміни статистики гравців у грі **Stalzone** (КВ, сесійні бої, дуелі або звичайні вилазки). Програма надає зручний графічний інтерфейс для моніторингу ефективності бійців.

---

## 🚀 Гайд з використання

1. **Встановлення:** Завантажте та запустіть `SAR_Setup.exe` з розділу **Releases**. Під час інсталяції ви можете обрати будь-яку зручну папку для встановлення.
2. **Перший запуск та підготовка:** 
   - Запустіть програму за допомогою ярлика на робочому столі або через меню "Пуск".
   - **Перший запуск:** У консольному вікні автоматично розпочнеться завантаження та розпакування автономних компонентів браузера Camoufox (~500 МБ). Зачекайте повідомлення `✅ Camoufox готовий до роботи!`.
   - **Повторні запуски:** Завантаження більше **не повторюватиметься** — програма лише миттєво перевірить версію та одразу відкриє веб-інтерфейс.
3. **Авторизація:** Натисніть кнопку **"Отримати сесію"** у лівій панелі для встановлення безпечного з'єднання з сайтом через браузер Camoufox.
4. **Створення блоку:** Створіть блок нікнеймів для аналізу та збережіть його у системі.
5. **Сканування:** Виберіть збережений блок із випадаючого списку та натисніть **"Сканувати зараз"**.
6. **Збереження зрізів:** 
   - Стандартний запис на початку дня (`00:00`) для відстеження загального прогресу.
   - Запис початку (`21:00`) та кінця КВ (`22:10`) для детальної аналітики кланових війн.
   - Екстрені зрізи під кнопкою отримання сесії для довільних замірів у будь-який момент.
7. **Аналіз та експорт:** Переглядайте результати в таблиці, сортуйте дані, скидайте зрізи за потреби або завантажуйте звіт у форматі **.csv** за допомогою спеціальної кнопки.
8. **Завершення роботи:** Закрити додаток і фоновий сервер можна, просто закривши вікно консолі або натиснувши `Ctrl + C`.
